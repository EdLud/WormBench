WormBench is a Lua modding layer for WA 3.8.1 that lets you code custom weapon and scheme behaviour.

If you are interested in modding, read the [guides](docs/starting-guide-1-your-first-mod.md), drop a folder under `Mods/`, pick its weapons and add-ons for your profile in the mod loader and you’re in.

Replays and WormNET are supported out of the box. Start from the [site](https://edlud.github.io/WormBench), check [features](docs/verbs.md), grab a [build](https://github.com/EdLud/WormBench/releases), enable an example, and see how far past “just another scheme” you can push a match or improve existing schemes.

**INSTALL:** Drop `wkLua.dll` next to `WA.exe`, click **Check Online** and **Install**.

**REQUIRES:** Windows 7 or later (or Wine/CrossOver), WormKit, Direct3D 9 (shader). Some WormKit modules clash with WormBench: [Requirements and compatibility](docs/requirements.md)
